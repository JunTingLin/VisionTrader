# Periodic Returns（Validation / Test）

## 計算說明

- 手續費 `fee = 0.001`（0.1%），資料與 split 定義同 [experiment_results.md](experiment_results.md)
- 報酬在 **TRADE_LEN = 21 個 business day 的再平衡網格**上計算：`月報酬` = 1 個 cycle，`年報酬` = 12 個 cycles
- **不使用** `df.resample('ME')`。21 個 business day 比一個日曆月短，網格會逐月往前漂移，會造成標籤與實際期間不符、部分 cycle 被丟棄、部分月份為空
- 每一列都標出該期的**實際起訖取樣日**；期末不足一個完整 cycle 的尾段會被捨棄並註明
- 每個架構的欄位是 **10 次獨立 run 的平均報酬**；benchmark 為買入持有（不受手續費影響）
