# Experiment Results Summary（Fee = 0.2%）

## 計算說明

- **手續費**：`fee = 0.002`（0.2%），為原始實驗 fee=0.001（0.1%）的 2 倍
- Portfolio weights（做多/空哪些股票）來自已訓練的 model（.pkl），僅重新模擬 PortfolioSim，不重新 train
- Model 來源：`src/outputs/` 與 `src/outputs_morris/`（Morris 學長提供的實驗）
- 新 wealth 存於 `src/outputs_fee002/`；`src/outputs/`、`src/outputs_morris/` 原始檔案完全未動
- ⚠️ 本文件與論文 Appendix D Table 14 **不是同一個實驗**：Table 14 為「以 κ=0.2% 從頭重訓」，本文件為「沿用 κ=0.1% 的 model 僅重新模擬」。數字不應直接互相對照
- **美國市場**：TRADE_MODE="M", DJIA `^DJI.csv`
  - 8/8/8 split：2000-01-01 ~ 2023-12-31，train[0:2086] / val[2086:4174] / test[4174:6260]
  - 5/3/2 split：2015-01-01 ~ 2025-03-31，train[0:1304] / val[1304:2087] / test[2087:2673]
- **台灣市場**：TRADE_MODE="M", 0050.TW `0050.TW.csv`
  - 5/3/2 split：2015-01-01 ~ 2025-03-31，train[0:1304] / val[1304:2087] / test[2087:2673]
- Benchmark 不受手續費影響（買入持有，不換手）
